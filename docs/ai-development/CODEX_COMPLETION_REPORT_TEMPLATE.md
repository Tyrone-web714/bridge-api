# Codex Completion Report Template

Every Codex implementation package must report:

A. Work package ID and title

B. Repository root

C. Backend path

D. Branch

E. Starting HEAD

F. Starting Git status

G. Approved scope implemented

H. Files created

I. Files modified

J. Files deleted

K. Generated artifacts

L. Runtime changes

M. Database changes

N. Migrations created

O. Migrations executed

P. Provider/model changes

Q. Production changes

R. Tests added or modified

S. Commands run

T. Exact test results

U. Full npm test result

V. Security findings

W. Tenant-isolation findings

X. Defects found

Y. Defects fixed

Z. Scope deviations

AA. Unapproved ideas identified but not implemented

AB. Deferred work

AC. Owner decisions required

AD. Final Git status

AE. Staging status

AF. Commit hash

AG. Local commit verification

AH. Remote commit verification

AI. Push status

AJ. Deployment status

AK. Migration status

AL. Recommended next package based strictly on the roadmap

AM. Whether the next package is already owner-approved

AN. Suggested commit message

The report must explicitly state whether Codex remained within approved scope, whether Codex added an unapproved feature, whether Codex identified but withheld optional ideas, whether any roadmap status was changed, what evidence supported each changed status, and whether the next package is already approved.
