# TSR AI Development Workflow

This directory is the repository-based handoff record for Truck-Safe Routing AI development. It coordinates the owner, ChatGPT as architecture and roadmap lead, Codex as implementation agent, and GitHub as the source-control preservation layer.

There is no automatic live connection, notification, shared memory, or direct prompt delivery between a ChatGPT conversation and the Codex desktop application. The approved handoff mechanism is the repository plus Codex's standardized completion report.

## Authoritative Records

- `TSR_AI_MASTER_ROADMAP.md` and `.json` define the approved roadmap.
- `CURRENT_AI_WORK_PACKAGE.md` and `.json` define exactly one active package.
- `CODEX_COMPLETION_REPORT_TEMPLATE.md` defines the required Codex completion report.
- `CHATGPT_HANDOFF_PROTOCOL.md` defines the owner-mediated handoff.
- `SCOPE_CONTROL_POLICY.md` and `SCOPE_CHANGE_PROPOSAL_TEMPLATE.md` define scope governance.
- `AI_MODEL_SELECTION_GATE.md` and `PRODUCTION_ORCHESTRATION_GATE.md` define gates that remain deferred.
- `SOURCE_CONTROL_POLICY.md` defines local, remote, push, commit, and deployment distinctions.

This workflow changes development-process documentation and validation only. It does not change TSR application behavior.
