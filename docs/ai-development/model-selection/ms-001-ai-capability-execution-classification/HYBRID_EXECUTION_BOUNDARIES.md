# Hybrid Execution Boundaries

| Capability ID | Deterministic Authority / AI Boundary |
| --- | --- |
| customer.account_guidance.presentation | Customer facts, spend, invoices, and service patterns remain D0; AI may only present supplied context. |
| driver.copilot.contextual_response | Backend route, hazard, delivery, and authorization facts remain authoritative; AI may answer only from supplied context. |
| operations.executive_dashboard_synthesis | D0 domain records remain authoritative; AI may synthesize and present priorities only. |
| prediction.delivery_failure_risk | Backend failure-rate calculations remain facts; AI may explain only after lightweight predictive benchmark. |
| route.risk_explanation.presentation | Deterministic route safety decision remains D0; AI may only explain supplied route facts. |
| safety.narrative_summary.presentation | D0 safety blockers and authority traces remain authoritative; AI may only summarize supplied evidence. |
| supervisor.daily_operations_report.narrative | Deterministic supervisor context remains source of truth; hosted narrative is advisory only. |
| warehouse.exception_summary.presentation | D0 warehouse readiness and discrepancy records remain authoritative; AI would only summarize supplied evidence. |
