# Lifecycle Model

AI-IEP-005A.2 Intelligence Lifecycle Framework is repository-only, deterministic, metadata-only, provider-neutral, and test-only. It does not implement predictive models, prompts, provider calls, runtime execution changes, deployments, pushes, commits, staging, or migrations.

Lifecycle states are DRAFT, DESIGNED, REGISTERED, VALIDATED, EXPERIMENTAL, PILOT, PRODUCTION_CANDIDATE, PRODUCTION, RESTRICTED, DEPRECATED, RETIRED, and ARCHIVED.
