# Warehouse Exception Model

Exception types: ROUTE_NOT_STAGED, ROUTE_STAGING_BLOCKED, LOAD_NOT_STARTED, LOAD_INCOMPLETE, LOAD_BLOCKED, LOAD_ASSIGNMENT_MISMATCH, PRODUCT_MISSING, PRODUCT_UNEXPECTED, QUANTITY_SHORT, QUANTITY_OVER, LOAD_EVIDENCE_MISSING, LOAD_EVIDENCE_STALE, LOAD_EVIDENCE_CONFLICT, ROUTE_DEPARTURE_NOT_READY, ROUTE_DEPARTURE_BLOCKED, SUPERVISOR_REVIEW_REQUIRED, WAREHOUSE_REVIEW_REQUIRED, INSUFFICIENT_EVIDENCE. Exceptions are evidence-based and deterministic.
