# Execution Profiles

Profiles are defined in profiles.js:

- DETERMINISTIC_ONLY
- ULTRA_LOW_COST
- BALANCED
- REAL_TIME_OPERATIONAL
- BACKGROUND_BATCH
- SAFETY_CRITICAL
- PRIVACY_RESTRICTED
- PREMIUM_APPROVAL_REQUIRED

Profiles define allowed/forbidden strategies, cost ceilings, latency targets, retry policy, cache policy, escalation policy, fallback policy, human-review posture, hosted-inference permission, local-inference preference, and logging level.
