# Dataset Schema

The canonical dataset schema is implemented in `bridge-api/services/intelligenceExecution/benchmarkDatasetFramework.js` and source manifests under `bridge-api/benchmarks/datasets`. Required areas include identity, capability association, status, purpose, source, privacy, quality, evaluation support, coverage, governance, integrity, and source evidence.

Unknown values remain explicit and do not silently become approved, public, synthetic, benchmark-ready, false, or zero.
