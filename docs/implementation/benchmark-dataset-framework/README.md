# Benchmark Dataset Framework

AI-IEP-004A.2 adds a repository-native, provider-neutral benchmark dataset framework for TSR intelligence capabilities. It defines dataset and case contracts, validation, lookup utilities, deterministic generated artifacts, coverage reporting, conservative templates, and small synthetic test-only datasets.

This package does not execute benchmarks, compare providers, rank strategies, calculate cost, activate premium models, expose a public API, write databases, or change production behavior.
