# Expected-Result Authority Model

The framework separates canonical facts, deterministic outputs, acceptable advisory interpretations, reference examples, prohibited claims, and human-review judgments. Reference text is an example, not the only correct wording, unless an exact assertion explicitly requires it.

Safety facts and deterministic route constraints remain authoritative over narrative output. Employment-impact cases must remain advisory and reject disciplinary, termination, compensation, or hiring decisions unless future governance authorizes otherwise.
