# Benchmark Dataset ID Standard

Dataset IDs use `<capability-id>.benchmark.<purpose>`. IDs are lowercase, stable, provider-neutral, model-neutral, Organization-neutral, customer-neutral, employee-neutral, route-neutral, and independent of file path.

Aliases may point to canonical IDs, but retired IDs must never be reused. Replacement datasets use `replacementDatasetId` and must point to a different known dataset.
