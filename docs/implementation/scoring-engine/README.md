# README

AI-IEP-004A.4 adds a provider-neutral benchmark scoring engine downstream from evaluation. It consumes validated evaluation runs and produces score records, aggregates, gates, thresholds, completeness, confidence, sensitivity analysis, and deterministic reports.

## Boundaries

- Test-only repository artifacts.
- No production scoring policy, provider ranking, model ranking, production recommendation, cost-effectiveness, TCO, or ROI.
- No live providers, production data, database persistence, migrations, deployments, public API, or runtime routing changes.
