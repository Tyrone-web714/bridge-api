# OBSERVATION TO DIMENSION MAPPING

Mappings are explicit and versioned. Safety observations map to safety, policy observations map to policy or employment governance, privacy observations map to privacy, structural observations map to structured output quality, cost observations map to cost observability, and timing observations map to latency.

## Boundaries

- Test-only repository artifacts.
- No production scoring policy, provider ranking, model ranking, production recommendation, cost-effectiveness, TCO, or ROI.
- No live providers, production data, database persistence, migrations, deployments, public API, or runtime routing changes.
