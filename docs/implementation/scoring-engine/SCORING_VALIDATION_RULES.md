# SCORING VALIDATION RULES

Validation rejects invalid profiles, invalid requests, incompatible evaluation runs, unsupported dimensions, bad weights, bad normalization, unmapped required evidence, unknown converted to zero, stale generated artifacts, and prohibited recommendation or cost-governance fields.

## Boundaries

- Test-only repository artifacts.
- No production scoring policy, provider ranking, model ranking, production recommendation, cost-effectiveness, TCO, or ROI.
- No live providers, production data, database persistence, migrations, deployments, public API, or runtime routing changes.
