# CORE SCORE DIMENSIONS

Core dimensions include correctness, safety, policy compliance, privacy, security, employment governance, structured output quality, factual grounding, refusal behavior, insufficient evidence handling, reliability, latency, resource efficiency, cost observability, explainability, reproducibility, coverage, and human review alignment.

## Boundaries

- Test-only repository artifacts.
- No production scoring policy, provider ranking, model ranking, production recommendation, cost-effectiveness, TCO, or ROI.
- No live providers, production data, database persistence, migrations, deployments, public API, or runtime routing changes.
