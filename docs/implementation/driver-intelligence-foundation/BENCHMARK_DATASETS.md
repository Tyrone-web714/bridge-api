# Benchmark Datasets

The synthetic benchmark catalog covers normal, advisory, warning, review-required, and insufficient-evidence outcomes.

Benchmark themes:

- on-route driving
- route resumed
- route deviation
- speed below threshold
- speed at advisory threshold
- advisory-speed driving
- speed between thresholds
- warning-speed driving
- stale speed evidence
- repeated speed warnings
- stop arrival
- stop departure
- unknown stop geometry
- low bridge approach
- bridge outside threshold
- restricted road approach
- no-through-truck approach
- local-delivery exception
- residential-area approach
- residential prohibition
- road closure
- missing GPS
- unknown speed
- unknown position
- unknown driver state
- missing hazard acknowledgement
- missing route geometry

All benchmark records are synthetic and test-only.
