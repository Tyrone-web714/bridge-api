# Advisory Model

Advisories are deterministic outputs generated from rule results.

Supported advisory types:

- `REDUCE_SPEED`
- `RETURN_TO_ROUTE`
- `LOW_BRIDGE_AHEAD`
- `RESTRICTED_ROAD_AHEAD`
- `NO_THROUGH_TRUCK_AHEAD`
- `RESIDENTIAL_AREA_ADVISORY`
- `REVIEW_REQUIRED`
- `UNABLE_TO_DETERMINE`
- `ACKNOWLEDGE_HAZARD`

Advisories are not provider-generated, not production commands, and not disciplinary recommendations.
