# Scope

AI-IEP-005B.2 is limited to the Driver Intelligence Foundation.

In scope:

- Driver profile contract and synthetic driver fixtures.
- Driver operational state and route state assessment.
- Route adherence and deviation assessment.
- Stop progress, arrival, and departure event handling.
- Speed compliance advisories and warnings.
- Low bridge, restricted road, no-through-truck, and residential-area approach detection from supplied evidence.
- Hazard acknowledgement assessment.
- Deterministic advisories, explanations, reason codes, evidence records, confidence records, and human-review flags.
- Synthetic benchmark cases and deterministic generated artifacts.

Out of scope:

- Production API changes.
- Hosted AI execution.
- Provider calls.
- Predictive driver modeling.
- Employee scoring, ranking, or discipline.
- Database schema changes or migrations.
- Deployment, Cloudflare, R2, or object-storage changes.
