# Authoritative Data Boundaries

Every capability records authoritative sources, canonical facts, advisory outputs, prohibited claims, source-of-truth service, data classification, Organization scope, retention classification, and deterministic verification requirements.

Safety-sensitive capabilities keep deterministic routing and hazard rules authoritative. AI-generated text may explain or summarize supplied facts but cannot redefine them or override safety rules.

Employment-impacting outputs are advisory only unless explicit owner governance approves otherwise.
