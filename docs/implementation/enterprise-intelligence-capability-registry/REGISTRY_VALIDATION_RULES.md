# Registry Validation Rules

Validation rejects duplicate IDs, invalid ID format, provider/model names in IDs, missing required identity fields, invalid enum values, invalid version format, impossible lifecycle/status combinations, strategy conflicts, premium tier conflicts, human-review conflicts, unapproved autonomous action, unapproved cross-Organization use, unknown dependencies, cycles, invalid replacements, alias collisions, negative latency, invalid micro-USD values, unknown cost as zero, active capabilities without source evidence, and canonical facts without authoritative sources.

Errors include capability ID, field, rule, and safe corrective guidance.
