# Decision Request Schema

Decision requests bind a capability, capability version, execution profile, policy profile, score evidence, cost-governance evidence, thresholds, cost ceilings, dry-run flags, simulation flags, counterfactual requirements, and sensitivity requirements into a deterministic advisory decision request.

## Boundary

AI-IEP-004A.6 is repository-only, synthetic, offline, advisory, and test-only. It does not deploy code, call live providers, write production data, mutate object storage, change cloud configuration, enforce production budgets, activate premium execution, or make procurement recommendations.
