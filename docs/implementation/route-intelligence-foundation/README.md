# Route Intelligence Foundation

AI-IEP-005B.1 adds a repository-only Route Intelligence Foundation for deterministic truck-safety reasoning. It defines vehicle, route, hazard, restriction, assessment, explanation, benchmark, and integration artifacts without changing production routing endpoints, deployments, migrations, database state, object storage, or Cloudflare configuration.

Canonical legal and physical truck-safety rules remain authoritative. Any generated explanation is derived only from deterministic assessment facts.


Successful deterministic gates produce only a safe within known evidence status, not a universal safety guarantee.
