# Route Portfolio Model

The route portfolio model normalizes each route into route identity, organization, assigned driver, assigned vehicle, schedule, actual start, stop counts, progress percentage, route status, deviation state, hazard references, evidence completeness, evidence confidence, and human review state.

Route status values include not started, started, in progress, delayed, blocked, returning, complete, cancelled, insufficient evidence, and unknown.

Generated route portfolio evidence is in `generated/supervisor_route_portfolio_catalog.json`.
