# Exception Severity Model

Severity is assigned by deterministic safety-first rules.

Critical severity is used for low-bridge hazards and safety-rule route blocks. High severity is used for restricted road, no-through-truck, road closure, and speed warning events. Moderate severity is used for active deviations and meaningful operational delay. Low and unknown severities are used for evidence issues where facts are incomplete or uncertain.

Unknown severity remains unknown and requires human review.
