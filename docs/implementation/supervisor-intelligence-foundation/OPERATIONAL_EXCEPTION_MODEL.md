# Operational Exception Model

Operational exceptions are deterministic records derived from supplied route, driver, stop, hazard, and evidence facts.

Covered exception classes include route start delay, route progress delay, blocked route, route deviation, low bridge event, restricted road event, no-through-truck event, road closure, speed advisory, speed warning, GPS unavailable, stale evidence, conflicting evidence, stop delay, skipped stop, unresolved stop, missing delivery evidence, human review, and insufficient evidence.

Generated exception evidence is in `generated/supervisor_exception_catalog.json`.
