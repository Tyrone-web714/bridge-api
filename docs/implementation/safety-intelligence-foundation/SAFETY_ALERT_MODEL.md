# Safety Alert Model

Allowed next steps: REVIEW_ROUTE_SAFETY, REVIEW_LOW_CLEARANCE_HAZARD, REVIEW_TRUCK_RESTRICTION, REVIEW_ROAD_CLOSURE, REVIEW_ROUTE_VEHICLE_COMPATIBILITY, REVIEW_DRIVER_SAFETY_ADVISORY, REVIEW_SPEED_WARNING, REVIEW_SHARED_SAFETY_RECORD, REVIEW_CONFLICTING_EVIDENCE, REVIEW_MISSING_EVIDENCE, HOLD_FOR_HUMAN_REVIEW, NO_ACTION_REQUIRED, UNABLE_TO_DETERMINE.
