# Employment And Safety Guardrails

The supervisor daily report can mention driver-related operational facts supplied by deterministic source context, so it is classified as employee-related advisory output.

Guardrails:

- no autonomous discipline
- no termination, hiring, compensation, or demotion recommendations
- no employee ranking or performance scoring
- no override of safety or routing rules
- no claim that AI output is authoritative
- supervisors must interpret output against backend records and policies

Validation rejects prohibited autonomous employment/safety action language such as termination or discipline instructions.
