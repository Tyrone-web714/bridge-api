# Generated Artifacts

Generated artifacts include run catalog JSON/CSV/Markdown, observation index, outcome summary JSON/Markdown, safety findings, policy findings, privacy findings, execution metrics, cost observations, and replay report.

Artifacts are deterministic and contain no timestamps that cause churn.

## Guardrails

- Repository fixtures only; no production data.
- Offline/mock execution only; no live hosted provider call.
- No weighted scores, thresholds, winners, provider rankings, cost-effectiveness claims, production recommendations, or runtime routing changes.
- No database persistence, migrations, deployments, or public API surface.
