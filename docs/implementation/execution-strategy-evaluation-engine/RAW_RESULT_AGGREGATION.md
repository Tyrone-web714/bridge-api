# Raw Result Aggregation

Aggregates are descriptive counts by outcome, evaluation type, domain, severity, result class, unauthorized candidates, timeouts, schema failures, safety failures, policy failures, privacy failures, and unknown cost observations.

No aggregate is a quality score, production-readiness score, or recommendation.

## Guardrails

- Repository fixtures only; no production data.
- Offline/mock execution only; no live hosted provider call.
- No weighted scores, thresholds, winners, provider rankings, cost-effectiveness claims, production recommendations, or runtime routing changes.
- No database persistence, migrations, deployments, or public API surface.
