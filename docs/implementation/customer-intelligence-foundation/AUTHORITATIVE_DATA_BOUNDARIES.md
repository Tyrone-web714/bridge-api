# Authoritative Data Boundaries

Authoritative future runtime evidence remains in `organization_id`, `customer_accounts.account_number`, `daily_route_stops.account_number`, `daily_route_stops.id`, `daily_route_manifests.id`, `account_orders.id`, `account_orders.invoice_number`, `account_order_items.id`, `account_order_items.sku`, `delivery_deductions.id`, `delivery_settlements.id`, and existing route/driver/supervisor/warehouse/fleet intelligence outputs. Customer names are display labels, not relational identifiers. Cross-Organization aggregation is prohibited.
