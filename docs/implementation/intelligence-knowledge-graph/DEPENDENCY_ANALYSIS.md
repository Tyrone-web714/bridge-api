# Dependency Analysis

AI-IEP-004A.8 Intelligence Knowledge Graph is repository-only, deterministic, offline, provider-neutral, and test-only. It does not enable runtime planning, provider routing, production recommendations, graph databases, SPARQL, RDF, Neo4j, cloud graph services, deployments, migrations, object storage mutations, or production writes.

Dependency analysis reports direct dependencies, indirect dependencies, reverse dependencies, generated artifacts to refresh, documentation to review, and tests to rerun for a selected node.

The generated dependency matrix covers every graph node and is stored in generated/dependency_matrix.json. Type-specific dependency reports cover capabilities, datasets, policies, cost governance, decisions, governance, documentation, generated artifacts, and test scripts.
